# Makarya IDE - Documentation & Guide

Selamat datang di **Makarya**, IDE Neobrutalist & AI App Builder.

## Fitur Utama

- **Monaco Code Editor**: Editor kode canggih dengan manajemen tab, tampilan diff review, syntax highlighting, dan keyboard shortcut.
- **Chat Agent**: Asisten AI CLI terintegrasi yang mendukung `opencode` dan `claude` dengan fitur upload gambar clipboard & file browser.
- **API Tester**: Request builder API lengkap dengan dukungan proxy & pembuatan perintah cURL.
- **Database Explorer**: Alat manajemen basis data dan pengkodean query.
- **Marketplace & Plugins**: Perluas fungsi IDE dengan plugin kustom.

## Panduan Penggunaan

1. Klik tombol **Open Editor** di atas untuk mulai mengedit project.
2. Gunakan **Ctrl + E** untuk mencari dan membuka file dengan cepat.
3. Buka sidebar **Chat Agent** untuk berdiskusi dan meminta bantuan AI coding.
4. Lampirkan tangkapan layar menggunakan tombol **Browse** atau **Paste**.
